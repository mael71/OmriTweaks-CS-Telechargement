# OmriTweaks (version C#)

Optimisation de Windows 10/11 en un clic, adaptée à votre PC — **version stable 0.8.2**.

## Télécharger

👉 [**OmriTweaks.exe** (dernière version)](https://github.com/mael71/OmriTweaks-CS-releases/releases/latest/download/OmriTweaks.exe)

Un seul fichier, rien à installer : double-cliquez dessus. Windows demande les droits administrateur (nécessaires pour modifier les réglages du système).

> Au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires** puis **Exécuter quand même**.

## Ce que fait OmriTweaks

- **Accueil** : votre matériel, ses mesures en temps réel (processeur, mémoire, carte graphique, températures, disque, réseau, batterie) et les optimisations recommandées pour ce PC.
- **50 optimisations** classées par composant (Processeur, Carte graphique, Mémoire, Stockage, Réseau, Windows & services), chacune avec sa fiche : ce qu'elle fait, ses risques, réversible ou non.
- **Annuler** remet la valeur d'origine ; un **point de restauration** peut être créé avant chaque série.
- **Tweaks activés** : l'état réel de chaque réglage sur le PC.
- **Paramètres** : thèmes, couleurs, mise en page, animations, confirmations.

## Configuration requise

Windows 10 ou 11 (64 bits). Aucune autre installation.

## Fichiers

Paramètres et sauvegardes dans `%APPDATA%\OmriTweaks` (partagés avec la version Python d'OmriTweaks).
